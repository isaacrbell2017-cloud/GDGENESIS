# Changelog

## v1.3.0
- Blocks button: recolor your layout blocks to match (Keep, Themed, Dark, Bright).
- Beat sync: pulse triggers on every beat, following the level's speed and speed portals (BPM from the prompt or settings).
- Details module: tiny crosses, triangles and dot clusters for Mythic-level polish.
- New Null Space theme; better Heavenly, Hell and Modern looks; new quick prompts.
- Generating again now overrides earlier colors instead of fighting them.
- Triggers are configured directly on the objects for reliability.

## v1.2.0
- Added Claude Opus 5.5 and a Claude Effort setting (Default, Low, Medium, High, Extra High, Max).
- AI Timeout 0 = Auto: higher effort waits longer before falling back to offline.

## v1.1.0
- New high-quality menu: quality tiers (Featured, Epic, Legendary, Mythic), Selection / Whole Level, Fill style and a Modules page.
- Fill: decorate inside blocks with Glow, Rim, Dots, Tiles, Checker or Solid (fills enclosed holes).
- Whole Level mode decorates your entire layout with color sections that shift along the level.
- Real glow pieces along block edges, soft glow orbs, sparkles and background/ground colors.
- Fill pieces are always No Touch so they never change gameplay.

## v1.0.2
- Fixed a crash when pressing Generate.

## v1.0.1
- Default activation key is now E.

## v1.0.0
- First private build: pause-menu button, GD-style prompt popup, offline generator, Claude API mode, key activation, button sound effects.
